# Rails Devise Project

__A Ruby on Rails application with Devise authentication.__

## Getting Started

Clone or download zip file:

```bash
git clone https://github.com/GuilhermeCCunha/rails_devise_project.git
```

```bash
bundle install
```

```bash
yarn install
```
